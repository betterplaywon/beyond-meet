## 📱 3. 화면별 상세 설계

### 3.1 스플래시 화면 (Splash Screen)

**목적**: 앱 로딩 중 브랜딩 표시

**레이아웃**:
```
┌─────────────────────────────┐
│                             │
│                             │
│         [APP LOGO]          │
│                             │
│       Dating Connect        │
│                             │
│      [Loading Spinner]      │
│                             │
│                             │
└─────────────────────────────┘
```

**요소**:
- 앱 로고 (중앙)
- 앱 이름 (로고 하단)
- 로딩 스피너 (하단)

**지속 시간**: 2초

**전환**: Fade out → Welcome Screen

---

### 3.2 웰컴 화면 (Welcome Screen)

**목적**: 앱 소개 및 시작 유도

**레이아웃**:
```
┌─────────────────────────────┐
│      [Illustration 1]       │
│                             │
│   영상으로 만나는           │
│   새로운 사람들             │
│                             │
│   ● ○ ○                     │ ← 페이지 인디케이터
│                             │
│                             │
│   [시작하기 버튼]            │
│   [이미 계정이 있어요]       │
└─────────────────────────────┘
```

**슬라이드 (3장)**:

**슬라이드 1**:
- 일러스트: 영상 통화 이미지
- 제목: "영상으로 만나는 새로운 사람들"
- 설명: "실시간 영상 통화로 진짜 모습을 만나보세요"

**슬라이드 2**:
- 일러스트: 매칭 이미지
- 제목: "빠르고 간편한 매칭"
- 설명: "원하는 조건으로 필터링하고 즉시 연결하세요"

**슬라이드 3**:
- 일러스트: 안전 이미지
- 제목: "안전하고 즐거운 만남"
- 제목: "검증된 사용자와 안전하게 소통하세요"

**버튼**:
- "시작하기" (Primary)
- "이미 계정이 있어요" (Text Link)

### 3.13 영상 통화 화면 (Video Call Screen)

**목적**: 실시간 영상 통화

```
┌─────────────────────────────┐
│ ⏱ 03:24 / 05:00             │ ← 타이머
│                             │
│                             │
│                             │
│      [상대방 영상]           │ ← 전체 화면
│                             │
│                             │
│  ┌──────────┐               │
│  │ 내 영상   │               │ ← PIP (우측 상단)
│  └──────────┘               │
│                             │
│                             │
│  ────────────────────────   │
│  [🎤] [📹] [🔄] [🌫] [❌]   │ ← 컨트롤
└─────────────────────────────┘
```

**요소**:

**상단**:
- 타이머 (좌측): "03:24 / 05:00"
- 네트워크 품질 표시 (우측)

**영상 영역**:
- 상대방 영상: 전체 화면
- 내 영상: PIP (우측 상단, 탭 시 전환)

**하단 컨트롤 (아이콘 버튼)**:
- 🎤 마이크 음소거/해제
- 📹 비디오 끄기/켜기
- 🔄 카메라 전환 (전면 ↔ 후면)
- 🌫 배경 블러/변경
- ❌ 통화 종료 (빨간색)

**상태 표시**:
- 마이크 음소거 시: 버튼에 슬래시 표시
- 비디오 끄기 시: 내 영상 → 아바타 표시

## 🎭 4. 인터랙션 및 애니메이션

### 4.1 버튼 인터랙션

```typescript
// 버튼 탭 시
onPress: {
  scale: 0.95,
  duration: 200ms,
  easing: 'ease-in-out'
}
```

**햅틱 피드백**:
- 중요 액션 (통화 수락, 거절): Heavy Impact
- 일반 버튼: Light Impact

### 4.2 화면 전환

**스택 네비게이션**:
- 슬라이드 인/아웃 (좌→우)
- Duration: 300ms

**탭 네비게이션**:
- Fade 전환
- Duration: 200ms

**모달**:
- Slide up from bottom
- Duration: 300ms
- 배경: 반투명 오버레이 (rgba(0,0,0,0.5))

### 4.3 로딩 상태

**스피너**:
- 회전 애니메이션
- Primary Color
- 크기: 40x40px

**스켈레톤 UI**:
- 친구 목록, 통화 기록 등
- 로딩 중 스켈레톤 표시
- Shimmer 애니메이션

### 4.4 토스트 메시지

**성공**:
- 배경색: Success (#00B894)
- 아이콘: ✓
- 위치: 상단
- Duration: 3초

**에러**:
- 배경색: Error (#FF7675)
- 아이콘: ✗
- 위치: 상단
- Duration: 3초

## 🎯 7. 주요 사용자 시나리오

### 시나리오 1: 랜덤 매칭으로 새로운 사람 만나기

```
사용자: 홍길동 (28세, 남성)
목표: 새로운 사람과 영상 통화

1. 홈 화면에서 "랜덤 매칭 시작하기" 버튼 탭

3. 매칭 성공 → "김영희" 프로필 미리보기
4. 3초 카운트다운
5. 영상 통화 화면 진입
6. 5분간 통화 (카메라 전환, 배경 블러 사용)
7. 통화 종료
8. 통화 종료 화면 → "친구 추가하기" 버튼 탭
9. 홈 화면 복귀
```

```
사용자: 홍길동 (28세, 남성)
목표: 친구 목록에 있는 김영희와 통화

1. 친구 목록 탭 선택
2. "김영희" 카드 옆 통화 버튼 (📞) 탭
3. 통화 요청 전송
4. 김영희 앱에 푸시 알림 표시
5. 김영희가 수락
6. 영상 통화 화면 진입
7. 통화 진행
8. 통화 종료
```
