# 마케팅 에셋 가이드 (Android / Play Store)

## 1. 스크린샷 촬영 가이드

### Android 스크린샷 사이즈 (필수)

| 타입       | 사이즈                | 필수 |
| ---------- | --------------------- | ---- |
| 스마트폰   | 1080 x 1920 px (최소) | O    |
| 태블릿 7"  | 1080 x 1920 px        | 권장 |
| 태블릿 10" | 1920 x 1200 px        | 권장 |

---

### 필수 스크린샷 목록 (5~8장 권장)

#### 스크린샷 1: 홈 화면 (메인)

- **화면**: 홈 스크린에서 "매칭 시작" 버튼이 보이는 상태
- **포인트**: 앱의 첫인상, 깔끔한 UI
- **캡션 문구**: "지금 바로 새로운 만남을 시작하세요"

#### 스크린샷 2: 매칭 중

- **화면**: 매칭 대기 애니메이션 화면
- **포인트**: 실시간 매칭 경험
- **캡션 문구**: "당신과 맞는 상대를 찾고 있어요"

#### 스크린샷 3: 영상 통화 화면

- **화면**: 영상 통화 진행 중 (테스트 영상 또는 목업)
- **포인트**: 핵심 기능인 영상 통화 UI
- **캡션 문구**: "5분 영상 통화로 진짜 매력을 확인하세요"
- **주의**: 실제 사용자 얼굴 노출 금지, 테스트 이미지 사용

#### 스크린샷 4: 친구 목록

- **화면**: 친구 탭에서 온라인 친구들이 보이는 상태
- **포인트**: 관계 유지 기능
- **캡션 문구**: "마음이 맞는 친구와 언제든 다시 연결"

#### 스크린샷 5: 프로필 화면

- **화면**: 프로필 편집 또는 조회 화면
- **포인트**: 개인화 기능
- **캡션 문구**: "나만의 프로필로 첫인상을 만들어보세요"

#### 스크린샷 6: 통화 종료 후 친구 추가 (선택)

- **화면**: 통화 종료 후 친구 추가 옵션
- **포인트**: 매칭 후 관계 발전
- **캡션 문구**: "좋은 대화였다면 친구로 연결되세요"

---

### 스크린샷 촬영 팁

1. **Android 에뮬레이터 스크린샷**

   ```bash
   # 에뮬레이터 스크린샷 촬영
   adb exec-out screencap -p > screenshot.png
   ```

2. **상태바 정리**

   - 시간: 9:41 권장
   - 배터리: 100%
   - 신호: 풀
   - Android Studio → Emulator → Extended Controls → Phone

3. **테스트 데이터 준비**

   - 더미 프로필 사진 (저작권 프리 이미지)
   - 적절한 닉네임 (한글/영문)
   - 친구 목록 3~5명

4. **디자인 프레임 추가 (선택)**
   - [Rotato](https://rotato.app/) - 디바이스 목업 생성
   - [Previewed](https://previewed.app/) - 무료 목업 도구
   - 배경색: 브랜드 컬러 (#FF8383 핑크) 또는 그라데이션

## 2. 앱 설명문 (Play Store)

### 앱 이름

**Beyond Meet - 영상 데이팅**

### 짧은 설명 (80자)

```
텍스트 없이 바로 영상 통화! AI 매칭으로 5분 만에 진짜 인연을 만나보세요.
```

### 상세 설명

```
Beyond Meet - 텍스트 없이 바로 만나는 새로운 데이팅

지루한 문자 대화는 그만! Beyond Meet에서는 바로 영상 통화로 상대방의 진짜 모습을 확인하세요.

━━━━━━━━━━━━━━━━━━━━

주요 기능

즉시 영상 매칭
- 버튼 하나로 바로 영상 통화 시작
- 텍스트 채팅 없이 얼굴을 보며 대화
- 5분 제한으로 부담 없는 첫 만남

스마트 AI 매칭
- 선호 조건에 맞는 상대 자동 연결
- 나이, 성별, 국가 필터 지원
- 원치 않는 상대 차단 기능

친구로 이어지는 관계
- 좋은 대화 후 친구 추가
- 온라인 친구에게 언제든 통화 요청
- 진정한 관계로 발전

안전한 만남
- AI 기반 콘텐츠 모더레이션
- 부적절한 행동 즉시 제재
- 신고 시스템으로 건전한 환경 유지

━━━━━━━━━━━━━━━━━━━━

이런 분께 추천해요

- 텍스트 대화가 지루한 분
- 상대방의 실제 모습이 궁금한 분
- 새로운 방식의 만남을 원하는 분
- 글보다 말이 편한 분

━━━━━━━━━━━━━━━━━━━━

사용 방법

1. 회원가입 (초대 코드 필요)
2. 프로필 작성
3. 매칭 시작 버튼 터치
4. 5분 영상 통화
5. 마음에 들면 친구 추가!

━━━━━━━━━━━━━━━━━━━━

참고사항
- 현재 베타 테스트 중입니다 (초대 코드 필요)
- 만 18세 이상만 이용 가능합니다
- 부적절한 행동 시 계정이 정지될 수 있습니다

문의: support@beyondmeet.app
```

## 3. 앱 아이콘 체크리스트

### Android 아이콘 사이즈

- **512 x 512 px** (Play Store용) - 필수
- Adaptive Icon 권장 (foreground + background 레이어)

### 현재 아이콘 위치

- `mobile/android/app/src/main/res/mipmap-*/ic_launcher.png`
- `mobile/android/app/src/main/res/mipmap-*/ic_launcher_foreground.png`
- `mobile/android/app/src/main/res/mipmap-*/ic_launcher_round.png`

### Adaptive Icon 설정

- 위치: `mobile/android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`
- 배경색: `#FF8383` (브랜드 핑크)

### 아이콘 디자인 가이드

- 앱 컬러 (#FF8383 핑크) 활용
- 심플한 아이콘 (영상 통화/하트 조합 권장)
- 텍스트 최소화 또는 제외
