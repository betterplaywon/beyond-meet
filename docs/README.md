# Beyond Meet - 프로젝트 문서

## 📚 문서 목록

### 1. [PRD.md](PRD.md) - 제품 요구사항 문서

**필독 우선순위: ⭐⭐⭐⭐⭐**

프로젝트의 전반적인 방향성과 요구사항을 정의한 핵심 문서입니다.

**주요 내용:**

- 프로젝트 비전 및 미션
- 타겟 사용자 페르소나
- Beta 테스트 전략 (20명 한정)
- 필수 기능 명세 (MVP)
- 추후 기능 계획
- 초대 코드 시스템
- 무료 인프라 전략
- 데이터 모델 (Prisma Schema 포함)
- 보안 및 개인정보 보호
- 성공 지표 (KPI)

**읽어야 하는 사람:**

- 모든 팀원 (개발자, 디자이너, PM)

### 2. [ARCHITECTURE.md](ARCHITECTURE.md) - 기술 아키텍처

**필독 우선순위: ⭐⭐⭐⭐⭐**

시스템의 기술적 구조와 구현 방법을 상세히 설명한 문서입니다.

**주요 내용:**

- 전체 시스템 아키텍처 다이어그램
- 프론트엔드 아키텍처 (React Native)
  - 폴더 구조
  - zustnad 상태 관리
  - React Navigation 라우팅
  - Agora SDK 통합
- 백엔드 아키텍처 (Node.js + Express)
  - API 서버 구조
  - Prisma ORM
  - Socket.io 실시간 통신
- 무료 인프라 배포 전략
  - Render.com (백엔드 호스팅)
  - Supabase (PostgreSQL + Storage)
  - Upstash (Redis)
  - Firebase (FCM)
  - Agora (WebRTC)
- 보안 아키텍처
- 모니터링 및 로깅

**읽어야 하는 사람:**

- 개발자 (필수)
- 기술 리더

- Week 8: 스토어 출시

- 위험 요소 및 대응 전략
- 출시 후 로드맵

**읽어야 하는 사람:**

- 모든 팀원
- PM (필수)

## 🎯 주요 참고 사항

### Beta 테스트 (20명 한정)

- 모든 기능은 20명이 동시에 사용 가능해야 함
- 초대 코드 시스템으로 사용자 수 제한
- 무료 인프라로 운영 ($0/월)

### 무료 서비스 한도

- **Agora**: 10,000분/월 (20명 기준 충분)
- **Render**: 750시간/월 (상시 가동 가능)
- **Supabase**: PostgreSQL 500MB + Storage 1GB
- **Upstash**: Redis 10,000 명령/일
- **Firebase**: FCM 무제한

### 핵심 제약사항

1. 통화 시간: 5분 제한
2. 사용자 수: Beta 단계 20명
3. 개발 기간: 50일
4. 비용: $0/월 (Beta)
